# Materiais de aprendizado

Esta pasta recebe arquivos que serão apresentados na página `learning.html`,
como PDF, Markdown, imagens, vídeos ou pacotes para download.

Adicione cada arquivo à pasta e cadastre-o em `manifest.json`:

```json
[
  {
    "title": "Primeiros passos",
    "type": "Guia em PDF",
    "description": "Como organizar a primeira semana no Kaiplan.",
    "file": "primeiros-passos.pdf",
    "linkLabel": "Ler o guia"
  }
]
```

O manifesto vazio é válido e exibe um estado inicial amigável. Use nomes de
arquivo sem espaços e mantenha apenas materiais próprios ou autorizados.
