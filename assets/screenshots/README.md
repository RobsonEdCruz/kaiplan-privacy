# Capturas de tela

Coloque as imagens do aplicativo nesta pasta. Prefira arquivos WebP ou AVIF
verticais, todos com a mesma proporção (a recomendada é 9:16).

Depois, edite `manifest.json`. Cada item aceita:

- `title`: título exibido abaixo da imagem;
- `file`: nome exato do arquivo nesta pasta;
- `alt`: descrição acessível da imagem;
- `description`: legenda curta.

Se um arquivo ainda não existir, o site exibirá automaticamente um placeholder
com o nome esperado.
